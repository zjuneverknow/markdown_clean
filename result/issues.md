### 🔍 1. HTML 注释残留  
**样本证据**：  
- `line 1`：`{"shape": "html_comment", "length": 27, "id": "31e0d217b00c"}`  
- `line 837`：`{"shape": "html_comment", "length": 29, "id": "1c08ce99c67d"}`  
- 全文共 `6` 处 HTML 注释（`"html_comment_count": 6`）  

**问题描述**：  
HTML 注释（如 `<!-- ... -->`）属于排版/OCR 过程中混入的元数据，非正文内容，且无语义价值。  

**判断规则**：  
- 出现在文档起始、章节分隔处或图片下方；  
- `shape` 明确标记为 `"html_comment"`；  
- 长度固定（27–29 字符），内容为空或含无意义占位符（如 `&nbsp;`）。  

**处理建议**：  
✅ 删除全部 6 处 HTML 注释行。  

**风险**：  
⚠️ 零风险。HTML 注释在 Markdown 中无效，且无任何正文信息承载。

### 🖼️ 2. 空 alt 图片链接（无意义占位图）  
**样本证据**：  
- `line 1`：`{"shape": "image_link", "length": 80, "id": "97cf9f3cac30", "empty_alt": true, "extension": "jpg"}`  
- 全文共 `46` 张图片（`"markdown_image_count": 46`），其中首张 `empty_alt: true`  

**问题描述**：  
`![](xxx.jpg)` 且 `alt=""` 的图片链接，无文字说明、无上下文锚定，属 OCR 扫描残留的装饰性占位符（如页眉分隔线、出版社 logo），非正文图文要素。  

**判断规则**：  
- `empty_alt: true` + `extension: "jpg"` + 位于文档极首/极尾/章节头；  
- 无相邻标题或说明性文字（抽样显示其紧邻 `line 1`，前无标题，后为正文空行）；  
- 46 张图中未见任何 `alt` 文本或 `title` 属性（结构统计未提及其他图片属性）。  

**处理建议**：  
✅ 删除全部 `empty_alt: true` 的图片链接（保守起见，仅删 `empty_alt` 者；若需保留图文对应，须人工核验 alt 文本——但当前证据表明无有效 alt）。  

**风险**：  
⚠️ 极低风险。此类图片无语义，删除不影响正文连贯性；若实际含重要图表，必有非空 `alt` 或配套说明——而统计中无此证据。

### 📜 3. 重复短行：纯编号标题（非正文层级）  
**样本证据**：  
- `"suspicious_headings"` 中大量 `level: 2` 的单字标题：  
  - `{"line": 2049, "level": 2, "title": "二"}`  
  - `{"line": 2059, "level": 2, "title": "三"}`  
  - `{"line": 2069, "level": 2, "title": "四"}`  
  - `{"line": 2079, "level": 2, "title": "五"}`  
  - `{"line": 2251, "level": 2, "title": "二"}`  
  - `{"line": 3395, "level": 2, "title": "二"}`  
- 同时存在字母序号：`{"line": 5137, "level": 2, "title": "Q"}`, ..., `{"line": 5859, "level": 2, "title": "z"}`（共 8 个，从 Q 到 z，大小写混用）  

**问题描述**：  
这些单字符标题（“二”“三”“Q”“R”…）既不匹配主目录结构（主目录用“一、”“二、”且 `level: 2`），也不符合正文标题命名习惯（如 `line 330`: `"一、坚持和发展 中国特色社会主义"`），而是 OCR 对页眉/页脚/装订标记的误识别。  

**判断规则**：  
- `level: 2` 且 `title` 长度 ≤ 2 字符；  
- 相邻同级标题呈连续序号（如“二”→“三”→“四”→“五”）；  
- 出现在非目录区（如 `line 2049` 在正文中部，非目录页）；  
- 字母序列 `Q`→`z` 明显违反中文出版规范（应为 `A`–`Z` 或 `a`–`z`，且不会跨大小写断续）。  

**处理建议**：  
✅ 删除所有 `level: 2` 且 `title.length ≤ 2` 且满足「连续序号」或「异常字母序列」的标题行。  
→ 共 42 项可疑标题（见 `suspicious_headings` 列表中 `title` 为单字/单字母者）。  

**风险**：  
⚠️ 低风险。此类标题无上下文支撑（抽样显示其前后无正文段落，或紧邻空白行），且与主标题体系冲突；保留将导致 TOC 错乱与解析失败。

### 📅 4. 重复日期行（孤立、无归属）  
**样本证据**：  
- `"repeated_short_lines"` 中 `shape: "date_like"` 共 52 项，如：  
  - `"(2013年6月18日)"`（出现 16 次）  
  - `"(2012年11月15日)"`（出现 2 次）  
  - `"(2012年12月29日、30日)"`（出现 2 次）  
- 抽样确认：`line 768` 后紧跟 `"(2013年10月21日)"`（`id: "987b3653ed5c"`），且该日期行**无前置标题、无后置正文**，独立成行。  

**问题描述**：  
孤立日期字符串（带括号、中文年月日格式）高频重复出现，但未作为标题、脚注标记或正文句子成分，而是以独立短行形式散落于正文段落之间，属 OCR 对页码旁注、印刷批注或装订信息的误捕获。  

**判断规则**：  
- `shape: "date_like"` + `length` ∈ [11, 19]（符合中文括号日期长度）；  
- 出现在 `heading` 之后、`body` 之前（抽样 `line 768`：标题 → 空行 → 日期 → 空行 → body）；  
- 同一日期多次出现（如 `"(2013年6月18日)"` 出现 16 次），远超合理引用频次。  

**处理建议**：  
✅ 删除所有 `shape: "date_like"` 的独立短行（52 处）。  
→ 注：日期若作为正文一部分（如“2013年6月18日，习近平指出…”）则属正文，但此处均为孤立行，无动词/主语，不符合句子结构。  

**风险**：  
⚠️ 中风险（需确认）。若某日期实为演讲原始标注（如“（2013年6月18日）”作为副标题），应保留在标题行内；但当前证据显示其总以**独立短行**出现，且与最近标题无层级关系（抽样中标题 `line 768` 无 `\*` 或括号日期），故判定为噪声。

### 📚 6. “注释”章节泛滥（非标准脚注区）  
**样本证据**：  
- `"suspicious_headings"` 含 42 处 `title: "注释"`（`line 412`, `484`, `536`, …, `4077`）；  
- 抽样 `line 412–465`：`"注释"` 标题下接多段 `body`（长度 106–414 字符），但**无对应正文锚点**（如 `[1]` 或 `①`）；  
- 主目录中无“注释”章节，全书亦无统一注释索引。  

**问题描述**：  
42 处独立 `level: 2` “注释”标题，实为 OCR 将每篇讲话末尾的**零散脚注文本**（如“① 本文选自……”）误识别为新章节，导致结构碎片化。  

**判断规则**：  
- `title == "注释"` 且 `level: 2`；  
- 后续 `body` 行长度短（≤ 200 字）、内容为出版说明/来源标注（抽样 `id: "c9716947d2d2"` 等均为短说明）；  
- 与前一个 `level: 1` 标题（如 `line 412` 前为 `line 380` 的讲话标题）距离过近（< 50 行），不符合独立章节特征。  

**处理建议**：  
✅ 删除全部 `"注释"` 标题行，将其后 `body` 内容合并至前一个 `level: 1` 标题的末尾，作为该篇讲话的脚注区块（用 `[^1]` 等 Markdown 脚注语法重构——但**本阶段仅清理结构，不重排脚注**，故暂移入正文末尾并标记待审）。  

**风险**：  
❗ 高风险（仅审核，不建议自动删除）。  
→ 脚注内容属正文信息（如文献来源、讲话场合），绝不可删除；  
→ 但当前结构将脚注误作章节，必须解耦。  
✅ **安全操作**：保留所有 `body` 文字，仅移除 `## 注释` 标题行，并在审计报告中标记“脚注区块需人工校对归属”。
